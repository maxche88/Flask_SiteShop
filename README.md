# Mamoto Flask Site

Интернет-магазин на **Flask** с расширенной функциональностью: полная система управления пользователями, админка, управления товарами, инструменты для QA-тестирования (создание чек-листов и баг-репортов).

---

## 🔧 Основные возможности

- **Аутентификация и авторизация**:
  - Регистрация, вход, подтверждение email
  - Восстановление пароля
  - Ролевая модель: `user`, `suser`, `admin`, `tester`
  - JWT-токены: генерация токена и установка его в cookies (время жизни токена задаётся в config.py)
- **Профиль пользователя**:
  - Редактирование имени и email (с подтверждением по email), cмена пароля
- **Админка**:
  - Админ панель с вкладками: пользователи, блокировка, логи `auth.log`, `chat.log`, `orders.log`, `product.log`, `system.log`
  - Блокировка по ip, отзыв токена
  - Управление товарами: администратор имеет возможность управлять товарами всех менеджеров
  - Сообщения: добавлена возможность добавлять тему диалога
- **Каталог и корзина**:
  - Каталог товаров на главной странице: возможность фильтрации и сортировка
  - Бэйдж с кол-вом добавленных товаров в корзину
  - Корзина: оформление покупки, удаление товара из корзины, подсчёт итоговой суммы, задать вопрос о товаре 
- **Сообщения**:
  - Сообщения: ведётся подчёт не прочитанных сообщений (выподающее меню иконки профиля, сообщения)
  - Возможность прикреплять файлы к сообщениям чата (в разработке)
- **QA-инструменты**:
  - Создание и редактирование чек-листов
  - Отметка результатов: **Passed / Failed / Blocked / Skipped**
  - Комментарии к пунктам чек-листа с всплывающими подсказками
  - Поддержка динамического обновления без перезагрузки (JS)
  - Отправка баг-репортов с вложениями (логи, скриншоты, ссылки)
  - Валидация расширений и размера файлов (задаётся в congig.py)    
- **Безопасность и надёжность**:
  - Уникальные имена файлов через UUID
  - Удаление старых файлов при обновлении
  - Структурированное логирование ошибок и отозванных токенов

---

## 🗃️ Технологии

- **Backend**: Python 3.10+, Flask, Flask-JWT-Extended, Flask-SQLAlchemy, FlaskMail
- **Frontend**: HTML(jinja2), CSS(flex, grid), JS (динамические формы, модальные окна, AJAX)
- **Database**: PostgreSQL
- **Migrations**: Flask-Migrate (Alembic)
- **Deployment-ready**: поддержка `DATABASE_URL`, `MAIL_SERVER` через переменные окружения

## 🚀 Запуск проекта

1. Клонируйте репозиторий:
  git clone https://github.com/maxche88/mamoto-flask-site.git
  cd mamoto-flask-site

2. Создайте и активируйте виртуальное окружение:
  python -m venv venv
  source venv/bin/activate  # Linux/macOS
  venv\Scripts\activate     # Windows

3. Установите зависимости:
  pip install -r requirements.txt

4. Настройте переменные окружения:
  DATABASE_URL=postgresql://user:password@localhost/data_db
  SECRET_KEY=ваш_секретный_ключ
  MAIL_PASSWORD=ваш_пароль_от_mail.ru

  **Подсказка**: Если у вас нет PostgreSQL:
    Скачайте [PostgreSQL для Windows](https://www.postgresql.org/download/windows/)
    Или используйте Docker: `docker run --name data-db -e POSTGRES_DB=data_db -e POSTGRES_USER=user -e POSTGRES_PASSWORD=pass -p 5432:5432 -d postgres`

5. Выполните миграции:
  flask db upgrade

6. Запустите:
  flask run

Примечания для разработчиков.
Все загруженные файлы обрабатываются с валидацией и уникальными именами (UUID).
При удалении пользователя удаляются связанные записи: сообщения, баг-репорты, вложеные файлы.
Чек-листы поддерживают полное обновление: изменение пунктов, сохранение комментариев и результатов.
Для удобства отладки: все ошибки и отозванные JWT-токены логируются в system.log.
